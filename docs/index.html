From test case to evidence, in one run

Lawak Store is a small shop with an admin panel. It is the system under test for this test automation. Each run picks a suite, runs Playwright and Bruno CLI, and produces a Word evidence document, an Excel workbook and a dashboard entry.

How a run works

Write the case once

One JSON source holds every case, step and expected result.

Generate

Scripts make the Excel workbook, the automation catalog and the tags.

Choose the suite

Smoke, Regression or Full Cycle, narrowed by phase, sprint and module.

Run

Playwright drives Edge. Bruno CLI checks the API. Each step saves a screenshot or a response.

Report

Word evidence, the workbook result columns and this dashboard update by themselves.

What is in the repository

  • demo/tests/: 41 Playwright UI cases with a caseStep fixture.
  • demo/api-testing/: the Bruno CLI collection, 9 API cases.
  • demo/scripts/: the run script and the Word, Excel and dashboard builders.
  • docs/: this site, served by GitHub Pages.

A known defect is planted on purpose. Checkout accepts a 4-digit postal code (DEF-001), so the dashboard can show a real failure and its report.
